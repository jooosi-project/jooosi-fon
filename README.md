> Jooosi Fon is an open-source WordPress plugin from [Jooosi](https://jooo.si). It was previously known as Yabe Webfont; version 2.x preserves compatibility with existing installations and content during the rebrand.

## Intro

Manage the fonts your WordPress site needs from one library. Import Google Fonts for local delivery, upload your own font files, connect an Adobe Fonts web project, and make every enabled family available in supported editors and page builders.

### Features

- 🔒 **Privacy-conscious Google Fonts:** Download and serve Google font files from your own WordPress installation instead of requesting them from Google in the visitor's browser.
- 📁 **Custom font library:** Upload and organize custom font files through the WordPress Media Library without FTP.
- ✨ **Google and Adobe Fonts:** Browse the Google Fonts catalog or synchronize the families from an Adobe Fonts web project.
- 🧬 **Variable font support:** Configure variable font axes and use multiple styles from a single font file.
- ⚡ **Optimized delivery:** Generate a cached stylesheet, preload eligible WOFF2 files, and choose linked or inline CSS output.
- 🧩 **Builder integrations:** Use the same font library across the block editor, themes, and popular visual builders.
- 📦 **Portable font bundles:** Export and import font definitions, optionally including locally hosted font binaries.
- 🔄 **Migration tools:** Import existing fonts from Bricks, Custom Fonts, Custom Adobe Fonts, Dplugins Font Hero, Elementor Pro, Fonts Plugin, and Use Any Font.
- 🌐 **Multisite compatible:** Activate and manage Jooosi Fon at the individual-site level in a WordPress Multisite network.

## Requirements

- WordPress 6.0 or later
- PHP 7.4 or later

## Installation

Install Jooosi Fon from the WordPress Plugins screen or upload a release archive. Activate the plugin, then open **WP Admin → Jooosi Fon** and add your first custom or Google font to the Library.

## Development

### Getting started

```bash
git clone https://github.com/jooosi-project/jooosi-fon.git
cd jooosi-fon
composer install
pnpm install
pnpm run dev
```

Prepare a release with `pnpm run release <major.minor.patch>`, review the generated commit and tag, then push both to trigger the deployment workflow. The Pro release major version is one higher than the corresponding Free release.

See the [changelog](./CHANGELOG.md) for notable changes.
